Getting Started

Validate your Posit Team deployment in minutes.

On this page

  • Install
  • Run a first test
  • Run against your server
  • Next steps

Install

uv tool install posit-vip
vip install

vip install installs Playwright's Chromium browser and the system libraries it needs. You can remove them later, along with other test artifacts, with vip uninstall.

Run VIP from your own workstation or a CI runner, not from the Connect, Workbench, or Package Manager servers. On a headless host, see Authentication.

Run a first test

Run VIP against Posit Public Package Manager:

vip verify --package-manager-url https://p3m.dev

The command should finish in under a minute and show a successful run with some tests skipped.

Run against your server

If you have Connect set up, run against it like this:

vip verify --connect-url https://connect.example.com --interactive-auth

The --interactive-auth flag opens a Chromium window so you can log in. After authentication completes, VIP runs the test suite headlessly and cleans up the session automatically.

If you have an API key, you can skip browser auth with --api-auth: 

export VIP_CONNECT_API_KEY="your-api-key"
vip verify --connect-url https://connect.example.com --api-auth

If some tests fail, fix what is wrong and rerun just those tests with --filter: 

vip verify --connect-url https://connect.example.com --interactive-auth --filter test_deploy_shiny

To check other products, add --workbench-url and --package-manager-url. Run vip --help to see every option.
